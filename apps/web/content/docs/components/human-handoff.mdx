## Usage

```tsx
"use client";

import { HumanHandoff } from "@/components/ui/human-handoff";

<HumanHandoff
  stage="waitingForPerson"
  reason="The customer asked for a refund outside the policy window. I can't decide this one."
  context={[
    { id: "customer", label: "Customer", value: "Priya Menon · 3 years, no refunds before" },
    { id: "tried", label: "I already tried", value: "Offered a replacement and a 30% credit. Both declined." },
  ]}
  onTakeOver={take}
/>
```

## Why it exists

Handoffs usually lose everything: the customer repeats themselves, whoever takes over
re-reads a transcript to find three facts, and nobody records what the agent already
tried — so the same rejected remedy gets offered twice.

## Features

- **The context is the component.** The facts a colleague would ask for in the first
  thirty seconds, including what the agent already tried.
- **The reason is in the agent's own words**, so the person knows why it stopped.
- **It works both ways.** Handing a finished job back to the agent is a real stage, not an
  afterthought.
- **Waiting holds completely still**, in the waiting colour, the same treatment approvals
  get.

## Props

| Prop | Type | Notes |
| --- | --- | --- |
| `stage` | `"agentHandling" \| "waitingForPerson" \| "personHandling" \| "returnedToAgent"` | Required. |
| `reason` | `string` | Why the agent stepped back, in its words. |
| `context` | `{ id, label, value }[]` | The facts the person receives. |
| `person` | `string` | Who has it now. |
| `waitingFor` | `string` | How long, formatted by you. |
| `onTakeOver` / `takeOverLabel` | `() => void` / `string` | |
| `onReturnToAgent` / `returnLabel` | `() => void` / `string` | |
| `title` | `string` | Defaults to `"Handover"`. |
| `headingLevel` | `2 \| 3 \| 4 \| 5 \| 6` | Defaults to `3`. |

## Accessibility

- A labelled `<section>`; the context is a description list, so labels and values are
  paired for screen readers.
- The stage is stated in words, not only by colour.
- Nothing animates in any stage.

## When not to use

- **One consequential action awaiting a decision:** use `AI Approval Gate`.
- **A question the agent could answer itself:** use `Agent Ask`.
- **Routing or assignment rules:** that's your queueing system, not this.
